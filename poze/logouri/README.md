# Logouri pentru bara de pe „Despre noi”

Numele fișierului trebuie să fie id-ul firmei din `src/data/clienti.ts`, de exemplu:

| Fișier | Firmă |
|---|---|
| `cnair.png` | CNAIR |
| `cfr.png` | CFR SA |
| `hidroelectrica.png` | Hidroelectrica |
| `apm-constanta.png` | Portul Constanța |
| `cj-prahova.png`, `cj-maramures.png` | Consiliile județene |
| `craiova.png`, `lugoj.png`, `sibiu.png`, `alba-iulia.png`, `onesti.png`, `fetesti.png` | Municipii |
| `aninoasa.png`, `persinari.png`, `bughea-de-jos.png`, `cozieni.png` | Comune |
| `ms-interproiect.png` | MS Interproiect Engineering |

Merg `.png`, `.svg`, `.jpg`, `.webp`. Cel mai bine arată un logo pe fundal
transparent (PNG sau SVG). Pe site logoul apare alb, monocrom, ca în bară.

Pentru o firmă nouă, adaugă un rând în `src/data/clienti.ts` sau cere-i lui Claude.
